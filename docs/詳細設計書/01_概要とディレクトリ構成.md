# 概要とディレクトリ構成

## 概要

要件定義（`../ISSUE管理ツール_要件定義.md`）に基づき、Laravel + Vue.js SPAの詳細設計を定義する。
既存のVueモック（`mock/`ディレクトリ）を流用・改修してAPI連携する実装を進める。

---
