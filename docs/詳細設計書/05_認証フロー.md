# 認証フロー

## 5. 認証フロー（Laravel Sanctum SPA認証）

```
1. GET /sanctum/csrf-cookie
   → Set-Cookie: XSRF-TOKEN=xxx（HttpOnly=false、JS から読める）

2. POST /api/v1/auth/login
   Headers: X-XSRF-TOKEN: xxx（Axios が自動付与）
   Body: { email, password }
   → Set-Cookie: laravel_session=yyy（HttpOnly=true）
   → 200 { id, name, email }

3. 以降の全 API リクエスト
   Headers: X-XSRF-TOKEN（Axios が Cookie から自動読み取り・付与）
   Cookie: laravel_session（ブラウザが自動付与）

4. ページリロード時
   GET /api/v1/auth/me
   → 200: authStore.user を復元
   → 401: /login へリダイレクト

5. ログアウト
   POST /api/v1/auth/logout
   → セッション破棄 → authStore.user = null → /login へリダイレクト
```

### Axios 設定（`resources/js/bootstrap.js`）

```javascript
import axios from 'axios'

axios.defaults.withCredentials = true
axios.defaults.headers.common['X-Requested-With'] = 'XMLHttpRequest'
// X-XSRF-TOKEN は Axios が XSRF-TOKEN Cookie から自動付与
```

### Laravel 側設定ポイント

| 設定箇所 | 内容 |
|---|---|
| `config/sanctum.php` | `stateful_domains` に `localhost` を追加 |
| `config/cors.php` | `supports_credentials: true`、`allowed_origins: ['http://localhost:5173']` |
| `.env` | `SESSION_DOMAIN=localhost`、`SANCTUM_STATEFUL_DOMAINS=localhost:5173,localhost` |
| `routes/web.php` | `Route::get('/{any}', fn() => view('app'))->where('any', '.*')` でSPAフォールバック |

### AuthController 実装方針

```php
// login
Auth::attempt(['email' => $request->email, 'password' => $request->password])
$request->session()->regenerate()  // セッション固定攻撃対策

// logout
Auth::guard('web')->logout()
$request->session()->invalidate()
$request->session()->regenerateToken()

// me
return new UserResource(Auth::user())  // 未認証なら 401
```
