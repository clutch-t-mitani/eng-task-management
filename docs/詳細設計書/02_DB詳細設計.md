# DB詳細設計

## 2. DB詳細設計

### `users`（ディレクター）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | ディレクターの一意な識別子 |
| name | VARCHAR(100) | NOT NULL | ディレクター氏名（画面表示・担当者表示で使用） |
| email | VARCHAR(255) | NOT NULL | ログインID。有効ユーザー内で重複不可 |
| active_email | VARCHAR(255) | GENERATED, UNIQUE（MySQL） | `deleted_at IS NULL` の場合のみ email を保持し、有効ユーザー内の一意性を保証 |
| password | VARCHAR(255) | NOT NULL | bcryptハッシュ化済みパスワード |
| remember_token | VARCHAR(100) | NULL | Laravel「ログイン状態を保持」用トークン |
| deleted_at | TIMESTAMP | NULL（ソフトデリート） | 退職等で無効化した日時。NULLなら有効ユーザー |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時（Laravel自動管理） |

### `engineers`（エンジニアマスタ）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | エンジニアの一意な識別子 |
| name | VARCHAR(100) | NOT NULL | エンジニア氏名（担当者プルダウン等で表示） |
| display_order | INT | NOT NULL, DEFAULT 0 | 一覧・プルダウンでの表示順。小さいほど上位 |
| deleted_at | TIMESTAMP | NULL（ソフトデリート） | 離任等で無効化した日時。NULLなら有効 |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

### `products`（プロダクトマスタ）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | プロダクトの一意な識別子 |
| name | VARCHAR(100) | NOT NULL | プロダクト名（ISSUE分類軸として使用） |
| description | TEXT | NULL | プロダクトの説明・備考 |
| display_order | INT | NOT NULL, DEFAULT 0 | 一覧での表示順 |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

### `product_repositories`（プロダクト⇔GitHubリポジトリ連携）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 連携レコードの一意な識別子 |
| product_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FK→products.id（ON DELETE CASCADE） | 対応プロダクト。1プロダクト1リポジトリ（UNIQUE） |
| owner | VARCHAR(100) | NOT NULL | GitHubのowner / org名（例: `laravel`） |
| repo | VARCHAR(100) | NOT NULL | リポジトリ名（例: `framework`） |
| last_synced_at | TIMESTAMP | NULL | 直近のWebhook反映または再同期開始時刻。未同期はNULL |
| last_sync_status | ENUM('success','partial','failed','skipped') | NULL | 直近反映/同期の結果ステータス |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

インデックス: `UNIQUE(product_id)`、`(owner, repo)`

### `issues`（ISSUE本体）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | ISSUEの一意な識別子 |
| title | VARCHAR(500) | NOT NULL | GitHub Issueタイトル。Webhook/再同期時はGitHubのIssue名で上書き |
| github_url | VARCHAR(500) | NOT NULL | 紐付くGitHub IssueのURL |
| director_id | BIGINT UNSIGNED | NULL, FK→users.id（ON DELETE RESTRICT） | 担当ディレクター。未割当はNULL。GitHub同期では上書きしない |
| engineer_id | BIGINT UNSIGNED | NULL, FK→engineers.id（ON DELETE RESTRICT） | 担当エンジニア。未割当はNULL。GitHub同期では上書きしない |
| product_id | BIGINT UNSIGNED | NOT NULL, FK→products.id（ON DELETE RESTRICT） | 所属プロダクト。必須 |
| status_id | TINYINT UNSIGNED | NOT NULL, DEFAULT 1 | ISSUEの進捗ステータスID。1=未着手、2=作業中、3=テスト中、4=完了、5=保留。GitHub同期では上書きしない |
| is_managed | TINYINT(1) | NOT NULL, DEFAULT 0 | 管理対象フラグ。1なら本ツールで進捗管理する。GitHub同期では上書きしない |
| display_order | INT | NOT NULL, DEFAULT 0 | 未グループISSUEおよび取り込み直後の全プロダクト共通表示順。小さいほど上位。GitHub同期では上書きしない |
| github_issue_number | INT UNSIGNED | NOT NULL | GitHub Issue番号。リポジトリ内で一意 |
| github_state | ENUM('open','closed') | NOT NULL | 最終反映時のGitHub状態 |
| github_synced_at | TIMESTAMP | NOT NULL | 最終反映日時 |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

インデックス: `director_id`、`engineer_id`、`product_id`、`status_id`、`is_managed`、`github_state`、`(product_id, display_order)`

複合UNIQUE: `(product_id, github_issue_number)`（同一リポジトリでの重複取り込み防止）

FK: `director_id` / `engineer_id` は `ON DELETE RESTRICT`（PHPレイヤーでソフトデリートするため物理削除されない）

### `issue_schedules`（日付管理）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | スケジュール行の一意な識別子 |
| issue_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FK→issues.id（ON DELETE CASCADE） | 対応するISSUE。1ISSUEに1行（UNIQUE） |
| planned_start | DATE | NULL | 着手予定日。ディレクターが手動入力する |
| actual_start | DATE | NULL | 実際の着手日。ディレクターが手動入力する |
| planned_end | DATE | NULL | 完了予定日。期日超過判定に使用。ディレクターが手動入力する |
| actual_end | DATE | NULL | 実際の完了日。ディレクターが手動入力する |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

インデックス: `planned_end`（期日超過クエリ用）、`planned_start`・`actual_start`・`actual_end`（日付絞り込みクエリ用、今後マイグレーションで追加予定）

### `group_issues`（グループ・ISSUE紐付け）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 紐付けレコードの一意な識別子 |
| group_id | BIGINT UNSIGNED | NOT NULL, FK→groups.id（ON DELETE CASCADE） | 所属グループ。グループ削除時に連動削除 |
| issue_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FK→issues.id（ON DELETE CASCADE） | 対象ISSUE。1ISSUEは1グループのみ（UNIQUE） |
| display_order | INT | NOT NULL, DEFAULT 0 | グループ内でのISSUE表示順 |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

インデックス: `(group_id, display_order)` 複合インデックス

グループはプロダクトに依存しない共通分類として扱い、1つのグループ内に複数プロダクトのISSUEを混在できる。

既存環境では `2026_05_11_000002_make_groups_product_independent` migration により、旧 `groups.product_id` を削除する。移行時は既存グループと `group_issues` を保持し、旧プロダクト順・グループ表示順・IDの順で `display_order` を全体順へ正規化する。

ロールバックでは、旧スキーマの `groups.product_id NOT NULL` を完全に復元できる場合だけ処理を実行する。事前検査で、すべてのグループに同一プロダクトのISSUEが1件以上所属していることを確認し、各グループの `product_id` を推定する。空グループまたは複数プロダクト混在グループが1件でも存在する場合は、復元不能なグループIDを含む例外をスキーマ変更前に投げ、ロールバックを中止する。成功時は `product_id` を `NOT NULL`、`products.id` への外部キー、`ON DELETE CASCADE` 付きで復元する。

### `sync_logs`（GitHub同期実行ログ）

| カラム | 型 | 制約 | コメント |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 同期ログの一意な識別子 |
| product_id | BIGINT UNSIGNED | NULL, FK→products.id（ON DELETE CASCADE） | 同期対象プロダクト。未登録リポジトリへのWebhookなど、プロダクト特定前のskipログではNULL |
| trigger | ENUM('webhook','manual_resync') | NOT NULL | 実行契機。webhook=GitHub自動反映、manual_resync=画面からの再同期 |
| triggered_by | BIGINT UNSIGNED | NULL, FK→users.id（ON DELETE SET NULL） | 再同期ボタンを押したディレクター。Webhook時はNULL |
| github_delivery_id | VARCHAR(100) | NULL | Webhookの `X-GitHub-Delivery`。再送・調査用 |
| status | ENUM('success','partial','failed','skipped') | NOT NULL | 処理結果。partial=途中まで成功、failed=ほぼ何もできなかった、skipped=対象外イベント・未登録リポジトリ等 |
| created_count | INT UNSIGNED | NOT NULL, DEFAULT 0 | 新規取り込み件数 |
| updated_count | INT UNSIGNED | NOT NULL, DEFAULT 0 | 既存更新件数 |
| skipped_count | INT UNSIGNED | NOT NULL, DEFAULT 0 | スキップ件数（PR・対象外） |
| failed_count | INT UNSIGNED | NOT NULL, DEFAULT 0 | 個別エラー件数 |
| error_message | TEXT | NULL | 致命的エラー内容（最初のエラーのみ）。レート制限時はリセット時刻を記録 |
| started_at | TIMESTAMP | NOT NULL | 同期開始時刻 |
| finished_at | TIMESTAMP | NULL | 同期終了時刻。途中クラッシュ時はNULL |
| created_at / updated_at | TIMESTAMP | NOT NULL | レコード作成・更新日時 |

インデックス: `(product_id, started_at DESC)`（直近ログ取得クエリ用）、`github_delivery_id`
